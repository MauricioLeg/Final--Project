About us

Debunked was created as a capstone project for the WDD330: Web Frontend Development II course at BYU-Idaho. Developed by Mauricio Leguizamon, a Software and Web Development student, this platform combines a passion for modern frontend engineering with a vital mission: empowering individuals to navigate the digital age. By translating complex logical fallacies and data manipulation tactics into interactive, multilingual challenges, Debunked serves as a practical tool to sharpen media literacy and foster critical thinking worldwide

Our Mission

In an era of rapid information sharing, the ability to analyze media critically is more important than ever. Debunked was designed to turn media literacy into an engaging, daily practice. Our goal is to equip users with the mental tools needed to spot logical fallacies, recognize emotional bias, outsmart data manipulation, and filter out sensationalism. We believe that a wiser world starts with questioning the headlines.

Key Features & Tech Stack

  • Component-Based Architecture: Engineered entirely with native JavaScript ES Modules (.mjs) to keep the codebase modular, scalable , and easy to maintain.
  • Dynamic UI Templating: Utilizing custom-built JavaScript templates to inject game puzzles and educational feeds dynamically into the DOM based on real-time data.
  • Multilingual Support (Localization): Features a robust client-side localization engine that fetches asynchronously hosted JSON translation files, instantly swapping the entire UI-including dynamic game assets-between languages seamlessly.
  • State Persistence: Leverages the Web Storage API (localStorage) ti track user game states, calculate daily completion parameters, and persist historical user streaks across browser sessions.
  • Responsive Frontend Design: Styled with advanced, fluid CSS layouts optimized for a seamless interactive experience across mobile devices, tablets, and desktop monitors.
